Размер скидки

Каждая строка — своя скидка для своего варианта и объёма. Если клиенту подходит несколько строк, берётся самая выгодная. «Объём от» значит «от этого объёма и больше». Для запечатанных флаконов объёма нет — для них делайте отдельную строку.

Описание и сроки

Скидка считается от цены аромата (доплата за флакон не уменьшается). Скидки не суммируются: на каждый аромат действует одна, самая выгодная. Акции «при покупке» действуют, когда условие выполняет другая позиция корзины, а не тот же аромат.

Массовая загрузка ароматов

Формат основного списка, одна строка = один аромат: [О]название[р-350][з-5000] — оригинал (р — цена на разлив за мл, з — цена запечатанного за шт.) и [М]название[р-400] — масляный (р — цена за мл). Цена 0 = «цена по запросу». Строки без [О]/[М] разбираются как раньше: бренд и название через запятую.
Apify API-токен
Каждый аромат из списка = 1 запуск Apify (≈ $0.002, 15–60 секунд). Токен хранится только в этом браузере.
Groq API-ключ и модель (для ИИ-описаний)
Описания для загруженных ароматов пишутся на вкладке «ИИ и картинки».

Очередь

Проверьте название и бренд, цены (масляный — за мл; оригинал: на разлив — за мл, запечатанный — за шт.) и нажмите «Опубликовать» (в поле цены можно нажать Enter). Картинка и описание подтянутся при публикации.

ИИ-описания (Groq)

Ключ хранится только в этом браузере. Взять его можно на console.groq.com → API Keys.

Описание пишется по бренду, названию и нотам. Заполненные описания не трогаются. Если Groq отвечает «слишком много запросов», страница ждёт 63 секунды и пробует снова — столько раз, сколько нужно, пока всё не загрузится или вы не нажмёте «Остановить». Вкладку не закрывайте, пока идёт загрузка.
